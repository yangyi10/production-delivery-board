# 生产交付计划看板

这是一个可在 VS Code 中直接运行的 Flask 网页原型，包含：

- 单个订单的多批次生产交付计划
- 订单评审、图纸、询盘、定标、供应商 PO、派单会等公共前置节点
- 同时支持单批交付和多批交付；只有需要时才增加批次
- 批次时间轴与进度展示
- 展开查看每批生产节点
- 在线修改任务状态
- 一键复制任意批次
- 删除多余批次后自动恢复为单批交付显示
- 按新开始日期自动平移全部节点日期

## 运行方法

1. 在 VS Code 中打开本文件夹。
2. 打开终端，安装依赖：

   ```bash
   python -m pip install -r requirements.txt
   ```

3. 启动网页：

   ```bash
   python app.py
   ```

4. 浏览器打开 `http://127.0.0.1:5000`。

当前版本使用内存保存数据，关闭程序后新增批次和状态修改会恢复。正式版本可再接入 SQLite 数据库。
