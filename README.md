# 生产交付计划看板

一个面向管理层的 Flask 生产交付看板原型，用于集中展示项目资料、关键任务、计划时间进度和实际完成情况。

## 当前功能

### 项目信息

- 维护项目名称、项目编号、客户、产品型号、启动日期和承诺交付日期
- 制定人自动读取当前系统用户，制定日期自动生成
- 项目备注支持自动保存
- 顶部圆环展示项目整体实际完成度

### 一级任务

- 默认提供图纸发布、派单、样品制造等关键里程碑模板
- 一级任务可新增、修改、删除和调整序号
- 支持计划日期、实际完成日期、负责人及状态维护
- 计划时间进度按照当前时间在计划周期中的位置自动计算
- 超过计划完成日期但尚未完成时，计划时间进度保持在 99%
- 填写实际完成日期后自动更新为“已完成”；清空日期后自动退回“进行中”

### 具体任务

- 每个一级任务均可展开并维护具体任务
- 具体任务包含任务名、任务描述、计划日期、实际完成日期、负责人和状态
- 新建任务必须填写完整，且计划完成日期不得早于计划开始日期
- “大货制造”下的具体任务支持复制为第二批、第三批等
- 具体任务状态自动汇总到所属一级任务
- 一级任务计划开始日期取具体任务中的最早日期，计划完成日期取最晚日期
- 全部具体任务完成后，一级任务自动完成并同步最晚实际完成日期

### 计划流程与审计

- 草稿阶段可以编辑项目资料和任务计划
- 确认计划后进入执行阶段，计划字段自动锁定
- 执行阶段可以更新实际完成日期和任务状态
- 修改已确认的计划前，需要填写调整原因并解锁计划
- 每次调整作为一条主记录，具体字段变化作为该记录下的明细
- 顶部项目信息卡右下角提供计划调整记录入口，点击后悬浮展示
- 项目结项后全部内容只读

## 本地运行

1. 在 VS Code 中打开项目目录。
2. 安装依赖：

   ```powershell
   py -m pip install -r requirements.txt
   ```

3. 启动 Flask：

   ```powershell
   py app.py
   ```

   如果 `py` 未加入 PATH，也可以使用 Python 的完整路径：

   ```powershell
   & 'C:\Users\杨\AppData\Local\Programs\Python\Python313\python.exe' app.py
   ```

4. 浏览器访问：<http://127.0.0.1:5000>

## 数据说明

当前版本使用进程内存保存数据。关闭或重新启动 Flask 后，页面中的新增、修改和日志会恢复为 `app.py` 中的初始数据。正式部署时建议接入 SQLite、PostgreSQL 等持久化数据库。

## Render 部署

- Build Command：`pip install -r requirements.txt`
- Start Command：`gunicorn app:app`

## 技术栈
